# R60 Label Carry Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `phig face rebuild` keeps an image's person labels by matching each
labelled face to the re-detected face in the same image, and counts and reports
the labels it could not match, instead of silently destroying them.

**Architecture:** A pure function in `core/faces.cpp`, `carry_labels`, matches an
image's labelled faces to its new detections by box overlap (intersection over
union), greedily and one-to-one. `FacesEngine::run` reads the labelled faces
inside the per-image transaction it already opens, deletes and re-inserts as
now, writes carried labels with `set_face_person`, and calls `auto_label_face`
only for faces still unlabelled. A new `FacesResult::labels_dropped` counts the
rest; the CLI warns with it and the ABI's `phig_faces_result` carries it.

**Tech Stack:** C++20, SQLite, OpenCV (YuNet + SFace), GoogleTest, CMake.

**Spec:** `plans/060-silent-loss-on-success.md`, section "R60 decision: labels
survive per image". Rule record: `rules/authorization.toml`, R60.

## Decisions this plan is built on

- **Box overlap is the only match test.** No embedding check: with the same
  model the embeddings are identical, and with a different model they are not
  comparable, so the check would drop every label in a model-change rebuild.
- **The overlap threshold defaults to 0.5** and Task 3 confirms it against the
  real collection before the engine uses it.
- **R60 becomes `partial`, not `holds`.** An unmatched label is still dropped
  without authorization; the rule keeps its statement and 060 keeps claiming it.
- **The ABI struct changes in place with no version bump.** Nothing outside the
  repo links libphig. A field change adds no symbols, so `kAbiSymbolCounts` and
  the macro-versus-CMake gate stay green. Same precedent as
  `docs/plans/2026-08-14-053-operations-take-ids.md`.

float box_overlap(const FaceInfo& a, const FaceInfo& b) {
    if (a.width <= 0 || a.height <= 0 || b.width <= 0 || b.height <= 0) return 0.0f;
    // 64-bit so a box near INT_MAX cannot overflow its far edge.
    int64_t ix = std::min<int64_t>(int64_t{a.x} + a.width, int64_t{b.x} + b.width) -
                 std::max<int64_t>(a.x, b.x);
    int64_t iy = std::min<int64_t>(int64_t{a.y} + a.height, int64_t{b.y} + b.height) -
                 std::max<int64_t>(a.y, b.y);
    if (ix <= 0 || iy <= 0) return 0.0f;
    double inter = static_cast<double>(ix) * static_cast<double>(iy);
    double area_a = static_cast<double>(a.width) * a.height;
    double area_b = static_cast<double>(b.width) * b.height;
    return static_cast<float>(inter / (area_a + area_b - inter));
}

LabelCarry carry_labels(const std::vector<LabelledFace>& labelled,
                        const std::vector<FaceInfo>& detected, float min_overlap) {
    LabelCarry out;
    out.person_ids.assign(detected.size(), -1);

    struct Pair {
        float overlap;
        size_t old_i;
        size_t new_i;
    };
    std::vector<Pair> pairs;
    for (size_t i = 0; i < labelled.size(); ++i) {
        for (size_t j = 0; j < detected.size(); ++j) {
            float o = box_overlap(labelled[i].face, detected[j]);
            if (o >= min_overlap) pairs.push_back({o, i, j});
        }
    }
    // Stable, so equal overlaps resolve in index order and a run is repeatable.
    std::stable_sort(pairs.begin(), pairs.end(),
                     [](const Pair& x, const Pair& y) { return x.overlap > y.overlap; });

    std::vector<bool> old_taken(labelled.size(), false);
    std::vector<bool> new_taken(detected.size(), false);
    for (const Pair& p : pairs) {
        if (old_taken[p.old_i] || new_taken[p.new_i]) continue;
        old_taken[p.old_i] = true;
        new_taken[p.new_i] = true;
        out.person_ids[p.new_i] = labelled[p.old_i].person_id;
    }
    for (bool taken : old_taken) {
        if (!taken) ++out.dropped;
    }
    return out;
}
```

// Measures how closely a fresh face detection reproduces the faces a collection
// already stores, to confirm kLabelCarryMinOverlap from data rather than choose
// it. Treats every stored face as labelled, so "carried" is the share of faces
// a rebuild would keep a label on.
//
// Read-only: opens the database with SQLITE_OPEN_READONLY and never constructs
// phig's Database, which opens read-write and migrates.
//
// Build by adding to the root CMakeLists.txt, temporarily:
//   add_executable(measure-redetect docs/plans/2026-11-07-060-measure-redetect.cpp)
//   target_link_libraries(measure-redetect PRIVATE phig-core)
// Run: ./build/measure-redetect <db> <stride>
#include <sqlite3.h>

#include <algorithm>
#include <cstdio>
#include <cstdlib>
#include <string>
#include <utility>
#include <vector>

#include "faces.h"
#include "hasher.h"

int main(int argc, char** argv) {
    if (argc != 3) {
        std::fprintf(stderr, "usage: %s <db> <stride>\n", argv[0]);
        return 2;
    }
    const size_t stride = static_cast<size_t>(std::max(1, std::atoi(argv[2])));

    sqlite3* db = nullptr;
    if (sqlite3_open_v2(argv[1], &db, SQLITE_OPEN_READONLY, nullptr) != SQLITE_OK) {
        std::fprintf(stderr, "cannot open %s\n", argv[1]);
        return 1;
    }

    std::vector<std::pair<int64_t, std::string>> images;
    sqlite3_stmt* s = nullptr;
    sqlite3_prepare_v2(db,
                       "SELECT DISTINCT i.id, i.path FROM images i "
                       "JOIN faces f ON f.image_id = i.id ORDER BY i.id",
                       -1, &s, nullptr);
    while (sqlite3_step(s) == SQLITE_ROW) {
        images.emplace_back(sqlite3_column_int64(s, 0),
                            reinterpret_cast<const char*>(sqlite3_column_text(s, 1)));
    }
    sqlite3_finalize(s);

    FaceDetector detector;
    size_t measured = 0, unreadable = 0, count_changed = 0, stored_total = 0, carried = 0;
    std::vector<float> best;

    for (size_t k = 0; k < images.size(); k += stride) {
        const auto& [id, path] = images[k];

        std::vector<LabelledFace> stored;
        sqlite3_prepare_v2(db,
                           "SELECT x, y, width, height FROM faces WHERE image_id = ? ORDER BY id",
                           -1, &s, nullptr);
        sqlite3_bind_int64(s, 1, id);
        while (sqlite3_step(s) == SQLITE_ROW) {
            LabelledFace lf{};
            lf.face.x = sqlite3_column_int(s, 0);
            lf.face.y = sqlite3_column_int(s, 1);
            lf.face.width = sqlite3_column_int(s, 2);
            lf.face.height = sqlite3_column_int(s, 3);
            lf.person_id = 1;
            stored.push_back(lf);
        }
        sqlite3_finalize(s);

        DecodeResult decoded = decode_image_with_warning(path);
        if (decoded.img.empty()) {
            ++unreadable;
            continue;
        }
        std::vector<FaceInfo> fresh = detector.detect(decoded.img);
        ++measured;
        if (fresh.size() != stored.size()) ++count_changed;
        stored_total += stored.size();

        for (const auto& sf : stored) {
            float b = 0.0f;
            for (const auto& f : fresh) b = std::max(b, box_overlap(sf.face, f));
            best.push_back(b);
        }
        carried += stored.size() - carry_labels(stored, fresh).dropped;
    }
    sqlite3_close(db);

    std::sort(best.begin(), best.end());
    auto pct = [&](double p) {
        if (best.empty()) return 0.0f;
        size_t i = std::min(best.size() - 1, static_cast<size_t>(p * best.size()));
        return best[i];
    };
    auto at_least = [&](float t) {
        return static_cast<size_t>(best.end() - std::lower_bound(best.begin(), best.end(), t));
    };

    std::printf("images with faces: %zu, measured: %zu, unreadable: %zu\n", images.size(),
                measured, unreadable);
    std::printf("images whose face count changed: %zu\n", count_changed);
    std::printf("stored faces: %zu, carried at %.2f: %zu (%.2f%%)\n", stored_total,
                kLabelCarryMinOverlap, carried,
                stored_total ? 100.0 * carried / stored_total : 0.0);
    std::printf("best overlap per stored face: p0.1 %.3f  p1 %.3f  p5 %.3f  p50 %.3f\n",
                pct(0.001), pct(0.01), pct(0.05), pct(0.5));
    std::printf("  == 1.0: %zu\n", at_least(1.0f));
    for (float t : {0.9f, 0.7f, 0.5f, 0.3f, 0.0f}) {
        std::printf("  >= %.1f: %zu\n", t, at_least(t));
    }
    return 0;
}
```

std::vector<LabelledFace> Database::get_labelled_faces_for_image(int64_t image_id) {
    const char* sql = R"(
        SELECT x, y, width, height, embedding, person_id
        FROM faces
        WHERE image_id = ? AND person_id IS NOT NULL
        ORDER BY id
    )";
    sqlite3_stmt* stmt;
    if (sqlite3_prepare_v2(db_, sql, -1, &stmt, nullptr) != SQLITE_OK) {
        throw std::runtime_error("Failed to prepare labelled faces read: " +
                                 std::string(sqlite3_errmsg(db_)));
    }
    sqlite3_bind_int64(stmt, 1, image_id);

    std::vector<LabelledFace> out;
    int rc;
    while ((rc = sqlite3_step(stmt)) == SQLITE_ROW) {
        LabelledFace lf{};
        lf.face.x = sqlite3_column_int(stmt, 0);
        lf.face.y = sqlite3_column_int(stmt, 1);
        lf.face.width = sqlite3_column_int(stmt, 2);
        lf.face.height = sqlite3_column_int(stmt, 3);
        // Matching uses the box only, so a malformed embedding blob is left
        // zeroed rather than costing the face its label.
        const void* blob = sqlite3_column_blob(stmt, 4);
        if (blob != nullptr &&
            sqlite3_column_bytes(stmt, 4) == static_cast<int>(sizeof(lf.face.embedding))) {
            std::memcpy(lf.face.embedding.data(), blob, sizeof(lf.face.embedding));
        }
        lf.person_id = sqlite3_column_int64(stmt, 5);
        out.push_back(lf);
    }
    sqlite3_finalize(stmt);
    if (rc != SQLITE_DONE) {
        throw std::runtime_error("Failed to read labelled faces: " +
                                 std::string(sqlite3_errmsg(db_)));
    }
    return out;
}
