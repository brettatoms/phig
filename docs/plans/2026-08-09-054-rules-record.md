# phig Rules Record — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Owned by:** `plans/054-reconcile-conflict-rules.md`
**Design:** `docs/specs/2026-08-09-phig-rules-design.md`

**Goal:** Turn phig's unwritten conflict, reconciliation and data-integrity rules into a machine-checked record set, with three generated views and CI checks that fail when the record and the code drift apart.

**Architecture:** Rules and operations live as hand-written TOML under `rules/`. One stdlib-only Python script loads them, runs ten checks against the source tree, the test binary and the plan index, and regenerates three markdown views (by invariant, by operation, by asset). The views are build artifacts nobody edits; the TOML is the only source of truth. An operation is a `core/` primitive with `cli`/`abi`/`http` surfaces hanging off it, so a rule bound to an operation is inherited by every surface.

**Tech Stack:** TOML (`tomllib`, Python 3.11+ stdlib), Python 3 stdlib only, GoogleTest, CMake, bash (CI).

## Global Constraints

- **Python 3.11+ standard library only.** No pip install, no PyYAML, no third-party imports. `tomllib` requires 3.11; the lint runner already has Python because it runs `pipx install`.
- **The record is TOML, never YAML.** YAML would add a pip dependency for readability alone.
- **`enforced_at` must resolve under `core/` or `libphig/`.** A rule enforced in `cli/` is a defect, not a record entry — see the design's §1.
- **Generated views are never hand-edited.** `rules/by-invariant.md`, `rules/by-operation.md`, `rules/by-asset.md` are output.
- **Whitespace hygiene.** No trailing whitespace on any line, no whitespace on blank lines. Applies to TOML, Python and markdown.
- **Commits require the user's explicit approval.** Steps below say "commit" and prepare the message; do not run `git commit` until the user approves. Never add Claude/AI attribution, `Co-Authored-By` trailers, or generated-with footers to any commit message.
- **Do not edit completed plans.** Cross-references are fine; status changes and rewrites are not.
- Existing test commands: `cmake -B build && cmake --build build`, `./build/phig-tests`, `ctest --test-dir build --parallel`.

- [ ] **Step 2: Extract the attachment rules**

At minimum: sidecars follow their parent's skip/overwrite/rename/dry-run fate
and are renamed to match a renamed parent; sidecars are never indexed as media;
a same-basename JPEG beside a RAW is carried, not indexed; `rm` trashes a
photo's sidecars alongside it and leaves same-stem RAW/JPEG siblings intact.

**And the rule commit `4435d0a` added, which is a sixth instance of the pattern
this whole plan documents.** A carried attachment's destination was guarded on
`mv` and not on `cp`: `move_file` declines and throws, but `atomic_copy_file`
ends in a rename that replaces silently, so a copy whose sidecar destination
already held a file destroyed it and reported `Errors: 0` — no error raised, no
restore snapshot. The sidecar loop and the RAW's sibling-JPEG carry both had it
and both predate the plan 038 review that fixed the Live Photo path. Write it as:

```toml
binds = ["organize.copy", "organize.move"]
protects = ["attachment"]
tests = [
    "OrganizeCarryNoClobber.CopyRefusesToClobberAnExistingSidecar",
    "OrganizeCarryNoClobber.CopyRefusesToClobberAnExistingSiblingJpeg",
    "OrganizeCarryNoClobber.StillCarriesWhenTheDestinationIsFree",
```

```python
#!/usr/bin/env python3
"""Load, check and render phig's rule records. Standard library only."""

import argparse
import dataclasses
import pathlib
import sys
import tomllib

STATUSES = {"holds", "partial", "violated", "unenforced"}
TEST_KINDS = {"witness", "conformance", "subprocess", "sanitizer"}
TIERS = {"engine", "boundary"}
SURFACES = {"abi", "cli", "http"}
NEEDS_OWNER = {"partial", "violated"}

REQUIRED = ("id", "tier", "concern", "statement", "rationale",
            "enforced_at", "protects", "tests", "test_kind", "status")


@dataclasses.dataclass
class Model:
    root: pathlib.Path
    rules: list
    operations: list
    concerns: list
    assets: list
    config: dict


def load(root):
    """Read every rules/*.toml under `root`. `root` is the repo root."""
    rules_dir = root / "rules"
    tax = tomllib.loads((rules_dir / "taxonomy.toml").read_text())
    config = tomllib.loads((rules_dir / "operations.toml").read_text())
    collected = []
    for path in sorted(rules_dir.glob("*.toml")):
        if path.name in ("taxonomy.toml", "operations.toml"):
            continue
        doc = tomllib.loads(path.read_text())
        for rule in doc.get("rule", []):
            rule["_file"] = path.name
            collected.append(rule)
    return Model(root=root, rules=collected, operations=config.get("operation", []),
                 concerns=tax["concerns"], assets=tax["asset"], config=config)


def check_schema(model):
    problems = []
    op_ids = {o["id"] for o in model.operations}
    asset_ids = {a["id"] for a in model.assets}
    seen = set()

    for rule in model.rules:
        rid = rule.get("id", "<no id>")
        for field in REQUIRED:
            if field not in rule:
                problems.append(f"{rid}: missing required field '{field}'")
        if rid in seen:
            problems.append(f"{rid}: duplicate rule id")
        seen.add(rid)

        if rule.get("tier") not in TIERS:
            problems.append(f"{rid}: tier must be one of {sorted(TIERS)}")
        if rule.get("concern") not in model.concerns:
            problems.append(f"{rid}: unknown concern '{rule.get('concern')}'")
        if rule.get("status") not in STATUSES:
            problems.append(f"{rid}: status must be one of {sorted(STATUSES)}")
        if rule.get("test_kind") not in TEST_KINDS:
            problems.append(f"{rid}: test_kind must be one of {sorted(TEST_KINDS)}")

        if rule.get("status") in NEEDS_OWNER and not rule.get("owner"):
            problems.append(f"{rid}: status '{rule.get('status')}' requires an owner")
        if rule.get("test_gap") and not rule.get("owner"):
            problems.append(f"{rid}: test_gap requires an owner")

        if rule.get("tier") == "engine":
            if "binds" not in rule:
                problems.append(f"{rid}: engine rule needs 'binds'")
            for op in rule.get("binds", []):
                if op not in op_ids:
                    problems.append(f"{rid}: binds unknown operation '{op}'")
            if "binds_surface" in rule:
                problems.append(f"{rid}: engine rule must not use 'binds_surface'")
        elif rule.get("tier") == "boundary":
            if "binds_surface" not in rule:
                problems.append(f"{rid}: boundary rule needs 'binds_surface'")
            for surface in rule.get("binds_surface", []):
                if surface not in SURFACES:
                    problems.append(f"{rid}: unknown surface '{surface}'")
            if "binds" in rule:
                problems.append(f"{rid}: boundary rule must not use 'binds'")

        for asset in rule.get("protects", []):
            if asset not in asset_ids:
                problems.append(f"{rid}: protects unknown asset '{asset}'")

    return problems


CHECKS = [check_schema]


def main(argv=None):
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--check", action="store_true", help="run every check")
    parser.add_argument("--root", default=pathlib.Path(__file__).resolve().parent.parent)
    args = parser.parse_args(argv)

    model = load(pathlib.Path(args.root))
    problems = [p for check in CHECKS for p in check(model)]
    for problem in problems:
        print(f"rules: {problem}", file=sys.stderr)
    if problems:
        print(f"rules: {len(problems)} problem(s)", file=sys.stderr)
        return 1
    print(f"rules: {len(model.rules)} rules, {len(model.operations)} operations, OK")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

```python
import re

OPEN_PLAN_STATUSES = {"designing", "planned", "in-progress"}
INDEX_ROW = re.compile(r"^\|\s*(\d{3})\s*\|[^|]*\|\s*([a-z-]+)\s*\|")


def plan_statuses(root):
```

```python
BANNER = "<!-- Generated by scripts/rules.py from rules/*.toml. Do not edit. -->"


def _badge(rule):
    status = rule.get("status", "?")
    owner = rule.get("owner")
    return f"{status} ({owner})" if owner else status


def render(model):
    by_id = sorted(model.rules, key=lambda r: r["id"])

    invariant = [f"# phig rules — by invariant\n", BANNER, ""]
    for concern in model.concerns:
        matching = [r for r in by_id if r["concern"] == concern]
        if not matching:
            continue
        invariant.append(f"## {concern}\n")
        for rule in matching:
            invariant.append(f"### {rule['id']} — {_badge(rule)}\n")
            invariant.append(f"{rule['statement']}\n")
            invariant.append(f"{rule['rationale']}\n")
            invariant.append("| | |")
            invariant.append("|---|---|")
            invariant.append(f"| Enforced at | {', '.join(f'`{s}`' for s in rule['enforced_at'])} |")
            bound = rule.get("binds") or rule.get("binds_surface", [])
            invariant.append(f"| Binds | {', '.join(f'`{b}`' for b in bound) or '—'} |")
            invariant.append(f"| Protects | {', '.join(rule['protects']) or '—'} |")
            invariant.append(f"| Evidence | {rule['test_kind']}: "
                             f"{', '.join(f'`{t}`' for t in rule['tests']) or 'none'} |")
            if rule.get("test_gap"):
                invariant.append(f"| Test gap | {rule['test_gap']} |")
            invariant.append("")

    operation = [f"# phig rules — by operation\n", BANNER, ""]
    operation.append("| Operation | " + " | ".join(model.concerns) + " |")
    operation.append("|---" * (len(model.concerns) + 1) + "|")
    for op in sorted(model.operations, key=lambda o: o["id"]):
        cells = []
        for concern in model.concerns:
            ids = [r["id"] for r in by_id
                   if r.get("tier") == "engine"
                   and r["concern"] == concern
                   and op["id"] in r.get("binds", [])]
            cells.append(" ".join(ids) if ids else "—")
        marker = "**" if op.get("destructive") else ""
        operation.append(f"| {marker}{op['id']}{marker} | " + " | ".join(cells) + " |")
    operation.append("")
    operation.append("Destructive operations are bold. A dash is a cell with no rule.")

    asset = [f"# phig rules — by asset\n", BANNER, ""]
    for entry in model.assets:
        asset.append(f"## {entry['id']} — rebuildable: {entry['rebuildable']}\n")
        asset.append(f"{entry['note']}\n")
        matching = [r for r in by_id if entry["id"] in r.get("protects", [])]
        if not matching:

        asset.append("| Rule | Concern | Status | Statement |")
        asset.append("|---|---|---|---|")
        for rule in matching:

        asset.append("")
```

# Phase 3 — Tests

**Phase 3's task list is written after Task 7, not now.** Which rules lack a
test is exactly what the enumeration discovers, and inventing that list here
would mean inventing the rule set — the work Phase 1 exists to do. Task 7's
report names every rule with `status = "holds"` and no test, every `test_kind =
"subprocess"` rule, and the adapter list for conformance rules; those become
Phase 3's tasks.

What is fixed in advance:

- **Conformance suites** use a gtest name generator emitting the operation id
  with `.` replaced by `_`, so check 9 can compare `--gtest_list_tests` output
  against `binds`. The suite name is the rule id plus `Conformance`, e.g.
  `R04Conformance`.
- **Adapters** live in a new `tests/rule_adapters.h`, one entry per operation:

```cpp
struct RuleAdapter {
    std::string id;                       // "remove.hard", matching operations.toml
    void (*destroy_row)(RuleFixture&);    // drive that primitive
};
```

- **Subprocess tests** for atomicity follow the existing `EXPECT_EXIT` pattern
  at `tests/test_libphig_abi.cpp:447` — kill a real run mid-operation and assert
  the database is in one of the states the rule declares reachable. No
  fault-injection seam is added to production code.
- **New tests must get a unique temp directory from `tests/temp_dir.h`.** A
  fixture that hardcodes a temp path passes alone and fails under
  `ctest --parallel`.
- Each new test's name goes into its rule's `tests` list, and
  `python3 scripts/rules.py --check --emit` is re-run, in the same commit.
