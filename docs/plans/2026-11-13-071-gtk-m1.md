# 071 — GTK M1, Browse and Annotate: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The GTK client becomes usable for browsing and annotating a
collection, and can start nothing that moves, deletes or overwrites: a gallery
with a sidebar, filters, search and sort; multi-select with tag, gallery and
favorite edits; a viewer with the image and its metadata; and a Scan… that
only adds.

**Architecture:** Every new capability is a `collection.h` function with a
fake, tested against a real catalog in `test-collection` (Tasks 1–5). The
gallery model is rebuilt per query from the query's ids, so a position always
names the same image and a selection resolves to ids without a fetch. The
window's logic lives in units that need no display — `background.h`,
`query`, `format`, `scan-watch` — tested on their own (Tasks 6–9). The
widgets that wire them are thin and checked by hand (Tasks 10–13, 15).
Metadata writes take the writer lock without waiting and report busy; the
index runs `ScanEngine::run_workers` only.

**Tech Stack:** C++23, GTK 4 / libadwaita (CI's gtk job: GTK 4.14,
libadwaita 1.5), GLib's `g_test`, CMake 3.20.

**Spec:** `plans/071-gtk-m1.md`. Read it before starting a task; it is
binding on scope, the safety boundary and testing.

**Branch:** the controller commits this script on `master`, then, with the
user's approval, creates `071-gtk-m1` from `master` and executes on it. No
step pushes.

**Checked while written:** every edit below was applied in order to a scratch
copy of `master` (`871c2c2`). Each task's tests failed where the script says
they fail, and after each task the gtk targets built under GCC with no

## Global Constraints

- **No destructive action anywhere in the client.** No Delete…, organize,
  remove, reconcile, face rebuild or thumbnail clean — not even as a disabled
  menu item. Metadata writes (tag add and remove, gallery set and clear,
  favorite) and an index that only adds are the only writes.
- **The index runs `ScanEngine::run_workers` and never `run_reconcile` or
  `run`.** It sets no `force`, no `faces`, no `thumbs`, and takes no writer
  lock, as libphig's index operation does.
- **Metadata writes take the writer lock without waiting** and, when another
  process holds it, change nothing and report busy (R55). Each write names its
  images by id (R78). Gallery set replaces (R79).
- **The catalog is the user's default** (`phig::gtk::default_catalog`), opened
  with `CatalogAccess::Write`. Opening never creates a catalog (R70); the index
  is the only path that does (`CatalogAccess::Create`).
- **Never write to or open `~/.local/share/phig/`, `~/.cache/phig/`,
  `~/.local/state/phig/`, `~/.config/phig/` or `/mnt/data/Pictures`**,
  read-only `sqlite3` included. Every test builds its own database in a temp
  dir. A hand-run `phig` or `phig-gtk` exports `HOME`, `XDG_CONFIG_HOME`,
  `XDG_DATA_HOME`, `XDG_CACHE_HOME` and `XDG_STATE_HOME` to a `mktemp -d`
  directory and unsets `PHIG_CATALOG`.
- **Only `gtk/src/collection.cpp` includes a `core/` header.** Widget code
  calls `collection.h`. A new `collection.h` function gets a fake in
  `gtk/tests/fake-collection.cpp`. `test-collection` tests `collection.cpp`
  against a database it builds; every other gtk test links the fake.
- **A `cv::Mat` never leaves `collection.cpp`.** Decoded pixels reach widget
  code as a `GdkTexture`.
- **No orientation handling in `gtk/`.** `core/`'s decoders apply EXIF
  orientation; thumbnail generation and the viewer's decode both go through
  them.
- **No exception unwinds into GLib or GTK.** Every function passed to GLib or
  GTK is `noexcept`; signals connect through `phig::gtk::connect`
  (`gtk/src/connect.h`); every `collection.h` function is `noexcept` and
  catches.
- **Widgets on the main thread; background work never reads `PhigApp`.** A
  worker gets its inputs by value and borrows only `coll`, which the held
  application keeps alive until the result is delivered.
- **`std::expected` and `std::move_only_function` are `gtk/`-only.** `core/`,
  `libphig/` and `cli/` use neither. This script changes no file outside
  `gtk/` except documentation and the plan.
- **No class hierarchies in code phig writes.** No gtkmm. Plain structs, free
  functions, `GRef<T>` (`gtk/src/gref.h`).
- **Only GTK 4.14 and libadwaita 1.5 API.** CI's gtk job runs on
  ubuntu-latest (24.04). No `AdwSpinner`, `AdwWrapBox`, `AdwToggleGroup`,
  `AdwBottomSheet` or `AdwButtonRow`.
- **Do not run clang-format over a whole existing `gtk/` file you only edit.**
  `main.cpp`, `test-gallery-model.cpp` and `test-thumb-loader.cpp` do not
  conform, and a reformat would hide the real diff. Format new files, and files
  that conform today (`collection.*`, `gallery-model.*`, `startup.*`,
  `fake-collection.*`, `test-collection.cpp`, `test-startup.cpp`), with the
  pinned clang-format.
- **gtk build directories go under `build/`**: `build/with-gtk` (GCC),
  `build/with-gtk-clang` and `build/with-gtk-asan`. Do not reconfigure the main
  `build/` with `PHIG_BUILD_GTK=ON`.
- **gtk tests run with no display:** `env -u DISPLAY -u WAYLAND_DISPLAY`.
  Widgets cannot be created there, so widget code has no automated test; the
  logic it wires is tested in Tasks 1–9 and the widgets are checked by hand in
  Task 15.
- **gtk targets do not get `-Werror`.** Each task's build step greps for
  `warning:` and `error:`, and a task finishes with none.
- **`g_assert_cmpstr` keeps only the pointer it is given.** Never pass it
  `f().c_str()` for a temporary string; the tests use an `assert_text` helper
  or a named local.
- **Comments describe the present.** Plan numbers and history go in commit
  messages, not comments.
- **Commit messages are plain prose, with no AI attribution** and no
  `Co-Authored-By` line.
- **Pushing needs the user's approval at the time.** No step in this script
  pushes.

## Decisions made in this script

071 settles scope, not layout. Each line below is a choice this script makes;
change any of them before Task 1 if you disagree.

1. **The gallery model is built from a query's ids** (`ids`, then `rows` per
   page), replacing M0's `count` and offset `page`. A position names the same
   image for the model's life, so a selection over pages never fetched
   resolves to exactly the ids shown, and a scan adding rows mid-browse cannot
   shift a selection onto other photos. Cost: 8 bytes a row in memory, read on
   a worker.
2. **A filter, search or sort change builds a new model** on a worker rather
   than resetting the old one: no stale-fetch bookkeeping, and the old model's
   dispose already waits for its in-flight fetch.
3. **Layout follows 047's GTK notes:** an `AdwNavigationView` whose root page
   holds an `AdwNavigationSplitView` (sidebar and gallery), with the viewer as
   an `AdwNavigationPage` pushed over it.
4. **A sidebar row replaces the filter with its scope** (All Photos clears it)
   and keeps the search text and sort; chips then narrow it further.
5. **Filters are added in a Filter popover**: a tag field adds one tag; the
   other fields set or clear theirs. Dates are From (on or after) and Before
   (strictly before), the CLI's `--after`/`--before` semantics unchanged.
6. **Search text without `*` or `?` matches anywhere in the full path**
   (`*text*`); text with either is a glob as typed. Case-sensitive, as
   `--match` is.
7. **Sort is a dropdown:** Newest First (default), Oldest First, Filename
   (A–Z), Largest First.
8. **A click selects, a double click or Enter opens the viewer.** M0's
   activate launched the system viewer; that moves to a viewer button. Shift,
   Ctrl and rubber-band selection come with `GtkMultiSelection`.
9. **The selection bar** (a `GtkActionBar` at the bottom) has Tag… (name, Add,
   Remove), Gallery… (name, Set, Clear; Set's tooltip says it replaces), Add
   to Favorites, Remove from Favorites, and Select None.
10. **Writes run on a worker** through `run_in_background`, on a second
    database connection serialized by a mutex, so a write never shares a
    transaction with a page read. A refused write is an `AdwToast` saying
    nothing changed, as M0 reports errors.
11. **After a write** the sidebar counts refresh; the gallery reloads only if
    the query filters on tags, gallery or favorite; the viewer re-reads its
    image.
12. **The sidebar's Tags list leaves out the built-in `favorite` tag** (it is
    the Favorites row) **and tags no image carries**, which `get_tag_counts`
    returns.
13. **The viewer decodes once, to a 4096 px longest edge**, through
    `decode_image_with_warning` — the decoder thumbnail generation uses, which
    applies EXIF orientation — so no `core/` change is needed. A video shows
    its keyframe. The 512 px thumbnail shows until the decode lands.
14. **The viewer's date is `effective_date`**, the value the gallery sorts by,
    not `get_best_date_str`, which also reads sidecar dates the sort does not.
15. **Camera and exposure show EXIF as phig stored it** (libexif's text, such
    as `1/500 sec.`), joined with ` · `; the make is prefixed only when the
    model does not already start with it.
16. **The metadata pane is always on the right, 300 px**, with no toggle. Tags
    are removable chips plus an entry; the gallery is an entry with Set and
    Clear; the favorite is a star in the viewer's header bar. Arrow keys step
    through photos; the picture takes focus when the page shows.
17. **Scan… is an `AdwAlertDialog`** with a folder chooser, Include subfolders
    (on) and Include hidden files and folders (off). One scan at a time.
18. **Scan progress is a bar under the header bar** (label, `GtkProgressBar`,
    Cancel), not an `AdwBanner`, which has no progress bar.
19. **The scan is polled every 100 ms from the main loop** (`ScanWatch`), as
    libphig's callers poll an operation, so no engine code runs on the main
    thread and no callback runs on a worker.
20. **The gallery reloads when a scan ends, not during it.**
21. **Closing the window during a scan cancels it** and waits for the files in
    progress; reads and writes hold the application until they deliver.
22. **A missing catalog is the "No Photos Yet" page with Scan…**; once a scan
    creates the catalog, the client opens it.
23. **`PhigApp` moves to `gtk/src/app.h`**, and new widget code goes in
    `browse.cpp`, `viewer.cpp` and `scan-ui.cpp`, so `main.cpp` keeps the grid,
    zoom and startup it has.
24. **The fake gains only what a test uses**: writes mutate its rows, `ids`
    honours tags, gallery, favorite, search and DateOldest, and its index is
    scripted so `ScanWatch` can be tested without a thread.
25. **The client takes no arguments** (Task 1). M0 accepted a catalog
    directory as `argv[1]`; 071 allows only the default, so `main` refuses an
    argument rather than ignoring it.
26. **R55 is not changed.** The gtk seam takes the writer lock without waiting
    as libphig does, but waiting instead would lose nothing, so this is each
    client's behaviour rather than a data-safety rule, and the code is in
    `gtk/`, where no rule anchors.
27. **Before keeps the CLI's meaning** and excludes its own day, so the client
    and `--before` agree.
28. **Search stays case-sensitive**, as `phig_glob` is. A case-insensitive
    match belongs in `core/` as its own change, not in the client.

Decisions 25–28 settle the draft's four open questions, agreed with the user
on 2026-11-13.

## Conflicts between 071 and the code

- `gtk/CLAUDE.md` says no seam call returns the whole collection. `ids`
  returns every match's id (not its row). Task 14 rewords the rule.
- `gtk/CLAUDE.md`'s removal rule names only `cmd_rm`'s `ConfirmFn`; 071 widens
  it to every destructive action. Task 14 writes the wider rule.
- 047 Screen 8 puts scan progress in an `AdwBanner` "with a progress bar";
  `AdwBanner` has a title and one button, no progress bar. Decision 18.
- 071 names `get_tag_counts` for the sidebar; it returns tags no image
  carries and the built-in `favorite`. Decision 12.
- M0 accepts a catalog argument. Decision 25.

A favorite is the built-in `favorite` tag, so `Filter::favorite` adds it to
the criteria's tags. `search_page` and `ids_matching` require an image to carry
as many distinct tags as the list names, so the list is deduplicated: a
favorite filter plus a `favorite` tag chip would otherwise match nothing.

The model takes the query's ids and fetches pages by id. A position therefore
names one image for the model's life: a selection over pages never fetched
resolves to exactly the ids shown, without a fetch, and a scan adding rows
while the user browses cannot move a selection onto other photos. A row
deleted after the ids were read keeps its position, as a row with only an id.

// A decoded image as a texture whose longest edge is at most max_edge.
GRef<GdkTexture> texture_from(cv::Mat img, int max_edge) {
    if (img.depth() == CV_16U) img.convertTo(img, CV_8U, 1.0 / 257.0);
    if (img.channels() == 1) cv::cvtColor(img, img, cv::COLOR_GRAY2BGR);
    if (img.channels() == 4) cv::cvtColor(img, img, cv::COLOR_BGRA2BGR);
    const int longest = std::max(img.cols, img.rows);
    if (longest > max_edge) {
        const double scale = static_cast<double>(max_edge) / longest;
        cv::Mat scaled;
        cv::resize(img, scaled,
                   cv::Size(std::max(1, static_cast<int>(img.cols * scale)),
                            std::max(1, static_cast<int>(img.rows * scale))),
                   0, 0, cv::INTER_AREA);
        img = std::move(scaled);
    }
    if (!img.isContinuous()) img = img.clone();
    GBytes* bytes = g_bytes_new(img.data, img.total() * img.elemSize());
    GRef<GdkTexture> texture =
        adopt(gdk_memory_texture_new(img.cols, img.rows, GDK_MEMORY_B8G8R8, bytes, img.step[0]));
    g_bytes_unref(bytes);
    return texture;
}

```cpp
#pragma once

#include <gio/gio.h>

#include <functional>
#include <optional>
#include <utility>

#include "gref.h"

namespace phig::gtk {

// Runs work on GLib's worker pool, then calls done with its result on the
// calling thread's default main context. The default GApplication, if there is
// one, is held until done has run, so a job started from the window keeps the
// process up until it delivers. done must check that the widgets it touches
// still exist.
//
// work runs on a worker thread: it may use only what it captured by value or
// was guaranteed to outlive it, never PhigApp and never a widget. The
// collection qualifies, because the held application keeps main from closing
// it until done has run.
template <typename T>
void run_in_background(std::move_only_function<T() noexcept> work,
                       std::move_only_function<void(T) noexcept> done) {
    struct Job {
        std::move_only_function<T() noexcept> work;
        std::move_only_function<void(T) noexcept> done;
        std::optional<T> result;  // set on the worker thread
        GRef<GApplication> app;   // held from submission until done has run
    };
    auto* job =
        new Job{std::move(work), std::move(done), std::nullopt, gref(g_application_get_default())};
    if (job->app) g_application_hold(job->app.get());

    GTask* task = g_task_new(
        nullptr, nullptr,
        [](GObject*, GAsyncResult* result, gpointer) noexcept {
            auto& j = *static_cast<Job*>(g_task_get_task_data(G_TASK(result)));
            j.done(std::move(*j.result));
            if (j.app) g_application_release(j.app.get());
        },
        nullptr);
    g_task_set_task_data(task, job, [](gpointer p) noexcept { delete static_cast<Job*>(p); });
    g_task_run_in_thread(task, [](GTask* t, gpointer, gpointer data, GCancellable*) noexcept {
        auto& j = *static_cast<Job*>(data);
        j.result.emplace(j.work());
        g_task_return_boolean(t, TRUE);
    });
    g_object_unref(task);
}

}  // namespace phig::gtk

    auto space = [](char c) { return std::isspace(static_cast<unsigned char>(c)) != 0; };
    while (!text.empty() && space(text.front())) text.remove_prefix(1);
    while (!text.empty() && space(text.back())) text.remove_suffix(1);
    return std::string(text);
}

int two_digits(std::string_view text, size_t at) {
    return (text[at] - '0') * 10 + text[at + 1] - '0';
}

    out.before = trimmed(form.before);

    if (!out.before.empty() && !is_date(out.before))

    const std::string tag = trimmed(form.tag);

bool is_date(std::string_view text) {
    if (text.size() != 10 || text[4] != '-' || text[7] != '-') return false;
    for (size_t i : {0, 1, 2, 3, 5, 6, 8, 9})
        if (std::isdigit(static_cast<unsigned char>(text[i])) == 0) return false;
    const int month = two_digits(text, 5);
    const int day = two_digits(text, 8);
    return month >= 1 && month <= 12 && day >= 1 && day <= 31;
}

namespace phig::gtk {

namespace {

std::string joined(const std::vector<std::string>& parts) {
    std::string out;
    for (const std::string& part : parts) {
        if (part.empty()) continue;
        if (!out.empty()) out += " · ";
        out += part;
    }
    return out;
}

}  // namespace

std::string camera_text(const Details& d) {
    if (d.model.empty()) return d.make;
    if (d.make.empty() || d.model.starts_with(d.make)) return d.model;
    return d.make + " " + d.model;
}

std::string exposure_text(const Details& d) {
    return joined({d.exposure_time, d.f_number, d.iso.empty() ? std::string() : "ISO " + d.iso,
                   d.focal_length});
}

std::string size_text(const Details& d) {
    std::string dimensions;
    if (d.width > 0 && d.height > 0)
        dimensions = std::to_string(d.width) + " × " + std::to_string(d.height);
    char* bytes = g_format_size(static_cast<guint64>(d.file_size > 0 ? d.file_size : 0));
    std::string out = joined({dimensions, bytes});
    g_free(bytes);
    return out;
}

std::string sharpness_text(const Details& d) {
    if (d.blur_score < 0) return "Not measured";
    char buf[32];
    g_snprintf(buf, sizeof buf, "%.1f", d.blur_score);
    return buf;
}

std::string progress_text(const IndexProgress& p) {
    if (p.total == 0) return "Finding files…";
    std::string out = std::to_string(p.done) + " of " + std::to_string(p.total) + " files";
    if (p.errors > 0) out += " · " + std::to_string(p.errors) + " failed";
    return out;
}

std::string summary_text(const IndexSummary& s) {
    std::string out = s.completed ? "Scan finished: " : "Scan cancelled: ";
    out += std::to_string(s.processed) + " added or changed, " + std::to_string(s.skipped) +
           " unchanged";
    if (s.errors > 0) out += ", " + std::to_string(s.errors) + " failed";
    return out;
}

std::string write_error_text(const WriteError& e) {
    if (e.busy) return "Nothing was changed: " + e.message + ". Try again when it finishes.";
    return "Nothing was changed: " + e.message;
}

std::string selection_text(uint64_t n) {
    return std::to_string(n) + (n == 1 ? " photo selected" : " photos selected");
}

#include <glib.h>

#include <expected>
#include <functional>
#include <memory>
#include <string>

#include "collection.h"

namespace phig::gtk {

using ScanProgressFn = std::move_only_function<void(const IndexProgress&) noexcept>;
using ScanDoneFn = std::move_only_function<void(std::expected<IndexSummary, std::string>) noexcept>;

// A running index, polled from the main context every kScanPollMs. on_progress
// runs on the main thread for each poll that found progress, and on_done runs
// there once, when the run ends; after on_done the watch is idle and may be
// destroyed, from inside on_done too. Destroying a watch before then cancels
// the run, waits for its thread and calls neither callback again.
inline constexpr guint kScanPollMs = 100;

struct ScanWatch;
struct ScanWatchClose {
    void operator()(ScanWatch* watch) const noexcept;
};
using ScanWatchPtr = std::unique_ptr<ScanWatch, ScanWatchClose>;

std::expected<ScanWatchPtr, std::string> scan_start(const std::string& catalog_dir,
                                                    IndexOptions options,
                                                    ScanProgressFn on_progress,
                                                    ScanDoneFn on_done) noexcept;

// Asks the run to stop; on_done follows with completed false.
void scan_cancel(ScanWatch& watch) noexcept;

}  // namespace phig::gtk
```

Create `gtk/src/scan-watch.cpp`:

```cpp
#include "scan-watch.h"

#include <utility>

namespace phig::gtk {

struct ScanWatch {
    IndexRunPtr run;
    guint source = 0;  // the poll's timeout source; 0 once it has stopped
    ScanProgressFn on_progress;
    ScanDoneFn on_done;
};

void ScanWatchClose::operator()(ScanWatch* watch) const noexcept {
    if (watch->source != 0) g_source_remove(watch->source);
    delete watch;  // the run's deleter cancels it and waits for its thread
}

namespace {

gboolean poll(gpointer data) noexcept {
    auto* watch = static_cast<ScanWatch*>(data);
    if (auto progress = index_poll(*watch->run)) watch->on_progress(*progress);
    auto result = index_result(*watch->run);
    if (!result) return G_SOURCE_CONTINUE;
    // on_done may destroy the watch, so nothing here touches it afterwards.
    watch->source = 0;
    ScanDoneFn done = std::move(watch->on_done);
    done(std::move(*result));
    return G_SOURCE_REMOVE;
}

}  // namespace

std::expected<ScanWatchPtr, std::string> scan_start(const std::string& catalog_dir,
                                                    IndexOptions options,
                                                    ScanProgressFn on_progress,
                                                    ScanDoneFn on_done) noexcept {
    auto run = index_start(catalog_dir, std::move(options));
    if (!run) return std::unexpected(std::move(run.error()));
    ScanWatchPtr watch(
        new ScanWatch{std::move(*run), 0, std::move(on_progress), std::move(on_done)});
    watch->source = g_timeout_add(kScanPollMs, poll, watch.get());
    return watch;
}

void scan_cancel(ScanWatch& watch) noexcept { index_cancel(*watch.run); }

}  // namespace phig::gtk
```

void reload(PhigApp& app) {
    if (!app.coll) return;
    const guint seq = ++app.query_seq;
    phig::gtk::Collection* coll = app.coll.get();
    PhigApp* a = &app;
    phig::gtk::run_in_background<std::expected<std::vector<int64_t>, std::string>>(
        [coll, query = app.query]() noexcept { return phig::gtk::ids(*coll, query); },
        [a, seq](std::expected<std::vector<int64_t>, std::string> found) noexcept {
            if (a->window == nullptr || seq != a->query_seq) return;
            if (!found) {
                show_status(*a, Status::Error, found.error());
                return;
            }
            attach_model(*a, std::move(*found));
            if (!a->measured && g_getenv("PHIG_MEASURE") != nullptr) {
                a->measured = true;
                const gint64 elapsed_us = g_get_monotonic_time() - a->startup_start_us;
                g_printerr("PHIG_MEASURE startup_ms=%.3f\n", elapsed_us / 1000.0);
            }
        });
    refresh_counts(app);
}

    std::move_only_function<phig::gtk::WriteResult(phig::gtk::Collection&) noexcept> write) {

    set_text(v.exposure, phig::gtk::exposure_text(d));
    set_text(v.size, phig::gtk::size_text(d));
    set_text(v.sharpness, phig::gtk::sharpness_text(d));
    gtk_flow_box_remove_all(v.tags);
    for (const std::string& tag : d.tags) gtk_flow_box_append(v.tags, tag_chip(app, tag));
    gtk_editable_set_text(GTK_EDITABLE(v.gallery_entry), d.gallery.c_str());
    gtk_button_set_icon_name(v.favorite, d.favorite ? "starred-symbolic" : "non-starred-symbolic");
    gtk_widget_set_tooltip_text(GTK_WIDGET(v.favorite),
                                d.favorite ? "Remove from Favorites" : "Add to Favorites");

void clear_details(Viewer& v) {
    for (GtkLabel* label : {v.filename, v.date, v.camera, v.exposure, v.size, v.sharpness})
        gtk_label_set_text(label, "");
    gtk_flow_box_remove_all(v.tags);
    gtk_editable_set_text(GTK_EDITABLE(v.gallery_entry), "");

// Shows the thumbnail while the decode is still running.
void request_thumbnail(PhigApp& app) {
    Viewer& v = app.viewer;
    if (!app.loader || v.full_shown || v.details.sha256.empty()) return;
    v.thumb_cancel = adopt(g_cancellable_new());
    PhigApp* a = &app;
    const guint seq = v.seq;
    thumb_loader_request(*app.loader, v.id, v.details.sha256, kViewerThumbSize,
                         v.thumb_cancel.get(),
                         [a, seq](ThumbResult result, GdkTexture* texture) noexcept {
                             Viewer& viewer = a->viewer;
                             if (a->window == nullptr || seq != viewer.seq || viewer.full_shown)
                                 return;
                             if (result == THUMB_OK)
                                 gtk_picture_set_paintable(viewer.picture, GDK_PAINTABLE(texture));
                         });
}

void load_details(PhigApp& app) {
    phig::gtk::Collection* coll = app.coll.get();
    PhigApp* a = &app;
    const guint seq = app.viewer.seq;
    phig::gtk::run_in_background<std::expected<phig::gtk::Details, std::string>>(
        [coll, id = app.viewer.id]() noexcept { return phig::gtk::details(*coll, id); },
        [a, seq](std::expected<phig::gtk::Details, std::string> found) noexcept {
            if (a->window == nullptr || seq != a->viewer.seq) return;
            if (!found) {
                show_toast(*a, found.error());
                return;
            }
            const bool first = !a->viewer.details_loaded;
            a->viewer.details = std::move(*found);
            a->viewer.details_loaded = true;
            show_details(*a);
            if (first) request_thumbnail(*a);
        });
}

void load_image(PhigApp& app) {
    phig::gtk::Collection* coll = app.coll.get();
    PhigApp* a = &app;
    const guint seq = app.viewer.seq;
    phig::gtk::run_in_background<std::expected<GRef<GdkTexture>, std::string>>(
        [coll, id = app.viewer.id]() noexcept {
            return phig::gtk::image(*coll, id, kViewerMaxEdge);
        },
        [a, seq](std::expected<GRef<GdkTexture>, std::string> decoded) noexcept {
            if (a->window == nullptr || seq != a->viewer.seq) return;
            if (!decoded) {
                show_toast(*a, decoded.error());
                return;
            }
            a->viewer.full_shown = true;
            if (a->viewer.thumb_cancel) g_cancellable_cancel(a->viewer.thumb_cancel.get());
            gtk_picture_set_paintable(a->viewer.picture, GDK_PAINTABLE(decoded->get()));
        });
}

void show_position(PhigApp& app, guint position) {
    Viewer& v = app.viewer;
    const guint n = g_list_model_get_n_items(G_LIST_MODEL(v.model.get()));
    if (position >= n) return;
    if (v.thumb_cancel) g_cancellable_cancel(v.thumb_cancel.get());
    v.position = position;
    v.id = phig_gallery_model_id_at(v.model.get(), position);
    v.seq++;
    v.full_shown = false;
    v.details_loaded = false;
    v.details = {};
    gtk_picture_set_paintable(v.picture, nullptr);
    clear_details(v);
    gtk_widget_set_sensitive(GTK_WIDGET(v.prev), position > 0);
    gtk_widget_set_sensitive(GTK_WIDGET(v.next), position + 1 < n);
    load_details(app);
    load_image(app);
}

void step(PhigApp& app, int delta) {
    Viewer& v = app.viewer;
    if (!v.model) return;
    if (delta < 0 && v.position == 0) return;
    show_position(app, delta < 0 ? v.position - 1 : v.position + 1);
}

        });

    gtk_picture_set_content_fit(v.picture, GTK_CONTENT_FIT_CONTAIN);
    /* Focus starts on the picture, so the arrow keys step through photos
     * rather than move the cursor in the tag entry. */

    GtkWidget* toolbar = adw_toolbar_view_new();
    adw_toolbar_view_add_top_bar(ADW_TOOLBAR_VIEW(toolbar), GTK_WIDGET(header));
    adw_toolbar_view_set_content(ADW_TOOLBAR_VIEW(toolbar), body);

    v.page = ADW_NAVIGATION_PAGE(adw_navigation_page_new(toolbar, "Photo"));
    adw_navigation_page_set_tag(v.page, "viewer");
    GtkEventController* keys = gtk_shortcut_controller_new();
    add_shortcut(GTK_SHORTCUT_CONTROLLER(keys), GDK_KEY_Left, on_left, app);
    add_shortcut(GTK_SHORTCUT_CONTROLLER(keys), GDK_KEY_Right, on_right, app);
    gtk_widget_add_controller(GTK_WIDGET(v.page), keys);
    connect<void(AdwNavigationPage*)>(v.page, "shown", [a](AdwNavigationPage*) noexcept {
        gtk_widget_grab_focus(GTK_WIDGET(a->viewer.picture));
    });
    // Dropping the model when the page is popped lets a gallery reload free the
    // old one.
    connect<void(AdwNavigationPage*)>(v.page, "hidden", [a](AdwNavigationPage*) noexcept {
        Viewer& viewer = a->viewer;
        if (viewer.thumb_cancel) g_cancellable_cancel(viewer.thumb_cancel.get());
        viewer.seq++;
        viewer.model.reset();
        gtk_picture_set_paintable(viewer.picture, nullptr);
    });
    adw_navigation_view_add(app.nav, v.page);
}

}

ScanForm& form_of(AdwAlertDialog* dialog) {
    return *static_cast<ScanForm*>(g_object_get_data(G_OBJECT(dialog), "phig-scan-form"));

void scan_finished(PhigApp& app, std::expected<phig::gtk::IndexSummary, std::string> result) {
    // The watch is idle once its on_done runs, and may be destroyed here.
    app.scan.reset();
    if (app.window == nullptr) return;
    gtk_widget_set_visible(app.scan_bar, FALSE);
    gtk_widget_set_sensitive(GTK_WIDGET(app.scan_button), TRUE);
    show_toast(app, result ? phig::gtk::summary_text(*result) : "Scan failed: " + result.error());
    if (app.coll)
        reload(app);
    else
        open_catalog(app);  // a scan creates a missing catalog
}

void scan_progressed(PhigApp& app, const phig::gtk::IndexProgress& p) {
    if (app.window == nullptr) return;
    const std::string text = "Scanning " + app.scan_folder + " — " + phig::gtk::progress_text(p);
    gtk_label_set_text(app.scan_label, text.c_str());
    if (p.total > 0)
        gtk_progress_bar_set_fraction(app.scan_progress,
                                      static_cast<double>(p.done) / static_cast<double>(p.total));
    else
        gtk_progress_bar_pulse(app.scan_progress);
}

void start_scan(PhigApp& app, phig::gtk::IndexOptions options) {
    if (app.scan) return;
    PhigApp* a = &app;
    std::string folder = options.directory;
    auto watch = phig::gtk::scan_start(
        app.catalog_dir, std::move(options),
        [a](const phig::gtk::IndexProgress& p) noexcept { scan_progressed(*a, p); },
        [a](std::expected<phig::gtk::IndexSummary, std::string> result) noexcept {
            scan_finished(*a, std::move(result));
        });
    if (!watch) {
        show_toast(app, "Could not start the scan: " + watch.error());
        return;
    }
    app.scan = std::move(*watch);
    app.scan_folder = std::move(folder);
    scan_progressed(app, {});
    gtk_progress_bar_set_fraction(app.scan_progress, 0.0);
    gtk_widget_set_visible(app.scan_bar, TRUE);
    gtk_widget_set_sensitive(GTK_WIDGET(app.scan_button), FALSE);
}

void on_folder_chosen(GObject* source, GAsyncResult* result, gpointer data) noexcept {
    GRef<AdwAlertDialog> dialog = adopt(static_cast<AdwAlertDialog*>(data));
    GFile* file = gtk_file_dialog_select_folder_finish(GTK_FILE_DIALOG(source), result, nullptr);
    if (file == nullptr) return;  // dismissed
    char* path = g_file_get_path(file);
    g_object_unref(file);
    if (path == nullptr) return;
    ScanForm& form = form_of(dialog.get());
    form.folder = path;
    g_free(path);
    gtk_button_set_label(form.folder_button, form.folder.c_str());
    adw_alert_dialog_set_response_enabled(dialog.get(), "scan", TRUE);
}

void choose_folder(ScanForm& form) {
    GtkFileDialog* chooser = gtk_file_dialog_new();
    gtk_file_dialog_set_title(chooser, "Choose a Folder to Scan");
    gtk_file_dialog_select_folder(chooser, GTK_WINDOW(form.app->window), nullptr, on_folder_chosen,
                                  g_object_ref(form.dialog));
    g_object_unref(chooser);
}
